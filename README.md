# CDIF Concepts
Properties for describing concepts of importance to a community. These may provide definitions for use in other CDIF profiles. A typical example would be a community glossary used for the purposes of naming variables. Likely based on SKOS, and possibly on OWL. 

Label for this profile still under discussion; suggestions: Concept Systems, Semantics, Concepts, Concept Representation, Concept Description - post to the WG to get a decision.
